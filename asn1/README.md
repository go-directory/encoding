# asn1

Package asn1 provides an assortment of helpers and types pertaining to ASN.1 encoding.

Note that this is NOT a copy of Go's "encoding/asn1" package. This package is entirely independent.

This package was designed specifically for use by the [Go Directory Project](https://github.com/go-directory).
